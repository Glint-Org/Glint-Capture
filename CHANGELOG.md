# Changelog

## 0.1.0

- Initial release
- `TelorDevice` presets for Pixel 7, Galaxy S23, iPhone 15, iPad Pro
- `TelorRule.screen()` and `TelorRule.template()` declarative API
- Alchemist-based golden screenshot runner
- CLI: `dart run telor_capture`
- Session JSON output compatible with Telor-Web and Telor-View
- Built-in templates: onboarding_flow, feature_highlights, settings_profile
- Example app with sample screenshot rules
- GitHub Actions CI workflow
