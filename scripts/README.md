# Glint-Capture scripts

Run from your Flutter app root:

```bash
chmod +x /path/to/Glint-Capture/scripts/*.sh
/path/to/Glint-Capture/scripts/glint-init.sh
/path/to/Glint-Capture/scripts/glint-capture.sh
```

These helpers scaffold capture and run screenshot collection for `session.json` + PNG output.
